**default shortcut keys**

## 🔹 Tab ဆိုင်ရာ Shortcut Keys (Tabs)

- **Ctrl + T** → New tab ဖွင့်  
    _(Open a new tab)_
    
- **Ctrl + W** → လက်ရှိ tab ပိတ်  
    _(Close current tab)_
    
- **Ctrl + Shift + T** → ပိတ်ပြီးသား tab ပြန်ဖွင့်  
    _(Reopen last closed tab)_
    
- **Ctrl + Tab** → နောက် tab ကို သွား  
    _(Go to next tab)_
    
- **Ctrl + Shift + Tab** → ရှေ့ tab ကို ပြန်သွား  
    _(Go to previous tab)_
    
- **Ctrl + 1 ~ 8** → နံပါတ်အလိုက် tab သွား  
    _(Jump to tab number)_
    
- **Ctrl + 9** → နောက်ဆုံး tab သွား  
    _(Go to last tab)_
    

---

## 🔹 Window ဆိုင်ရာ Shortcut Keys

- **Ctrl + N** → New window ဖွင့်  
    _(Open new window)_
    
- **Ctrl + Shift + N** → Incognito window ဖွင့်  
    _(Open incognito window)_ 
    
- **Alt + F4** → Chrome window ပိတ်  
    _(Close Chrome window)_
    

---

## 🔹 Page / Navigation Shortcut Keys

- **Alt + ←** → နောက်ပြန် (Back)
    
- **Alt + →** → ရှေ့သွား (Forward)
    
- **Ctrl + R** / **F5** → Page refresh  
    _(Reload page)_
    
- **Ctrl + Shift + R** → Hard refresh  
    _(Reload without cache)_
    
- **Esc** → Page loading ရပ်  
    _(Stop loading)_
    

---

## 🔹 Address Bar (URL Bar)

- **Ctrl + L**
    
- **Alt + D**  
    👉 Address bar ကို တန်းရွေး  
    _(Select address bar)_
    
- **Ctrl + Enter** → `.com` နဲ့ auto complete  
    _(example: google → google.com)_
    

---

## 🔹 Zoom Shortcut Keys

- **Ctrl + +** → Zoom in
    
- **Ctrl + -** → Zoom out
    
- **Ctrl + 0** → Default zoom (100%)
    

---

## 🔹 Search & Text

- **Ctrl + F** → Page ထဲမှာ စာရှာ  
    _(Find in page)_ 🔍
    
- **Ctrl + H** → History ဖွင့်
    
- **Ctrl + J** → Downloads ဖွင့်
    
- **Ctrl + D** → Bookmark ထည့် 
    

---

## 🔹 Developer / Power User (နည်းပညာ)

- **Ctrl + Shift + I**
    
- **F12**  
    👉 Developer Tools ဖွင့်  
    _(Open DevTools)_ 🛠️
    
- **Ctrl + Shift + J** → Console tab တန်းဖွင့်
    
- **Ctrl + U** → View page source  
    _(HTML source)_
