## ✅ CD Command Syntax

```bash
cd [directory-path]
```

---

## 📁 အသုံးများတဲ့ `cd` usage များ (မြန်မာဘာသာ + English simple)

|Command|ဖော်ပြချက် (Description)|
|---|---|
|`cd`|👉 Home directory ကို ပြန်သွားတယ် (go to home folder)|
|`cd ~`|👉 အတူတူပဲ `cd` လိုပဲ home folder သွားတယ်|
|`cd ..`|👉 တစ်လွှာအထက် folder ကိုသွားတယ် (go up one level)|
|`cd ../..`|👉 နှစ်လွှာအထက် folder သွားတယ် (go up two levels)|
|`cd /`|👉 Root directory ကိုသွားတယ်|
|`cd /etc`|👉 Absolute path နဲ့ `/etc` folder ကိုသွားတယ်|
|`cd myfolder`|👉 Relative path နဲ့ `"myfolder"` ကိုသွားတယ်|
|`cd -`|👉 နောက်ဆုံးသွားခဲ့တဲ့ directory ကို ပြန်သွားတယ် (toggle to previous folder)|

---

## 🎯 ဥပမာ (Examples)

```bash
cd
# go to home folder

cd Documents
# go to Documents folder (inside current folder)

cd /var/log
# go to log folder using absolute path

cd ..
# go up one level

cd -
# switch to previous working directory
```

---

##  Tip (အကြံပြုချက်လေး)

- Terminal ထဲမှာ `pwd` ဆိုတဲ့ command နဲ့ **မင်းရဲ့ current directory** ကို စစ်နိုင်ပါတယ်။
- Tab key ကို နှိပ်ရင် path auto-complete လုပ်နိုင်ပါတယ်။
