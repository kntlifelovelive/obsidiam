# Hacker Workflow Example

log analysis

```bash
cat access.log | awk '{print $1}' | sort | uniq -c
```

port scanning

```bash
nmap -sV target.com
```

interactive search

```bash
fd | fzf
```

open file

```bash
vim $(fd | fzf)
```
